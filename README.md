## Tools and Technologies
- Python
- Pandas and NumPy for data analysis
- Matplotlib and Seaborn for data visualization
- Jupyter Notebook

## Dataset
This project uses the Sample Superstore dataset to analyze sales, profit, product categories, regional performance, and discount patterns.

Dataset source: https://www.kaggle.com/datasets/vivek468/superstore-dataset-final

## Analysis Performed
- Analyzed overall sales, profit, orders, and units sold.
- Compared sales and profit across product categories and regions.
- Examined monthly sales and profit trends.
- Identified top-performing products and loss-making sub-categories.
- Investigated the relationship between discounts and profitability.

## Key Business Recommendations
- Review discount strategies for products with low or negative profit.
- Focus on product categories and regions that generate stronger profits.
- Investigate loss-making sub-categories and identify opportunities to reduce costs.
- Use monthly sales trends to support inventory and sales planning.

## Project Files
- `Task1_Sales_Analysis.ipynb` — Python analysis and visualizations.
- `charts/` — Generated charts from the analysis.

## How to Run
1. Download the dataset from the source linked above.
2. Open `Task1_Sales_Analysis.ipynb` in Jupyter Notebook.
3. Install the required libraries if needed: `pandas`, `numpy`, `matplotlib`, and `seaborn`.
4. Update the dataset file path in the notebook if necessary.
5. Run the notebook cells from top to bottom.

## Conclusion
This project demonstrates how Python-based data analysis can turn sales data into useful business insights. The findings can help businesses understand performance, identify profitability issues, and make more informed decisions.
